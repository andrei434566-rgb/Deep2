# Импорт CVAT и обучение Kern Analyzer

## 1. Подготовьте первую базу в CVAT

Экспортируйте задачу как **COCO 1.0** в ZIP-архиве. Для каждого объекта нужны:

- имя класса фации — например, DWCh;
- полигон (предпочтительно) или прямоугольник;
- исходное фото внутри ZIP-архива. Если CVAT выгрузил только аннотации, Kern Analyzer сам попросит выбрать папку с исходными JPG/PNG.

## 2. Импортируйте в Kern Analyzer

В верхнем меню выберите **File → Импорт разметки CVAT (COCO ZIP)…**. Приложение создаст отдельный проект в папке projects, извлечёт изображения, добавит контуры и сохранит проект.

Импортированные контуры считаются ручной проверенной разметкой. Они уже пригодны для обучения границ и основной метки фации.

## 3. Заполните описание слоя

Щёлкните правой кнопкой по контуру или выберите слой в дереве проекта. В карточке:

1. проверьте основную метку фации;
2. укажите глубины при наличии;
3. заполните доступные значения из 16 полей справочника;
4. нажмите **Сохранить**.

«Название породы» — это один из 16 параметров, а не замена коду фации.

## 4. Дообучение

Кнопка **Дообучить** экспортирует:

- изображения и полигонные метки YOLO для границ/фаций;
- файл attributes.jsonl — связь каждого вырезанного фрагмента с фацией и 16 параметрами.

Модель границ и фаций можно дообучать из приложения. attributes.jsonl предназначен для следующего модуля: многовыходного классификатора, который будет предсказывать 16 описательных параметров. Не запускайте обучение после каждого примера: собирайте проверенные пакеты. Для первой версии ориентир — 30–50 контуров на фацию.

## Поддерживаемые объекты

Поддерживаются стандартные COCO-полигоны, bbox и RLE-маски из CVAT. Многосоставная маска сохраняется как несколько редактируемых контуров одного класса. После импорта рядом с проектом создаётся `cvat_import_report.txt`: в нём указаны отсутствующие изображения и пропущенные повреждённые аннотации.
