# Пробный классификатор шести фаций

Используются первые шесть нумерованных папок из сбалансированного датасета:

```text
01_DWCh
02_DWChM
03_DWLd
04_DWLm
05_DWLp
06_DWTSh
```

В каждой папке берутся десять изображений: восемь идут в обучение, два — в
validation. Это только пробный запуск: validation из двух изображений на класс не
показывает реальную точность модели.

## Обучение

```powershell
python train_six_facies_classifier.py "C:\путь\к\1234566_balanced_crops"
```

Первый запуск может скачать `yolo11n-cls.pt` — предобученную небольшую модель. Итог
сохраняется в `six_facies_training/six_facies_best.pt`.

## Применение

```powershell
python run_boundary_classifier.py six_facies_training\six_facies_best.pt "C:\путь\к\фото_керна.jpg"
```

Второй скрипт сначала запускает алгоритм прямоугольных границ, вырезает каждый
прямоугольник и передает его классификатору. Для каждого пакета он печатает все шесть
вероятностей в порядке убывания и записывает их в `probabilities.json`.
