# Как скачать и запустить DeepCore 2

1. Откройте страницу **Releases** репозитория Deep2 и скачайте файл
   `DeepCore_2-Windows.zip` из последнего релиза.
2. Щёлкните по ZIP правой кнопкой мыши и выберите «Извлечь всё…».
   Не запускайте программу прямо из ZIP-архива.
3. Откройте распакованную папку и дважды щёлкните `DeepCore_2.exe`.
   Устанавливать Python, пакеты или дополнительные библиотеки не нужно.
4. При первом запуске Windows может показать SmartScreen, потому что программа
   пока не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом
   случае», только если ZIP скачан из официального репозитория Deep2.

Не удаляйте папку `_internal`, расположенную рядом с `DeepCore_2.exe`: в ней
лежат компоненты интерфейса, YOLO и модель сегментации. Свои проекты и
дообученные модели программа сохраняет отдельно, в папке `DeepCore 2 Data`
рядом с приложением.

Постоянная ссылка на загрузку последнего релиза:

`https://github.com/andrei434566-rgb/Deep2/releases/latest/download/DeepCore_2-Windows.zip`
