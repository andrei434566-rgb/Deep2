# Равномерное извлечение фрагментов из CVAT

1. В CVAT откройте Task → `Actions` → `Export task dataset`.
2. Выберите `COCO 1.0` и включите сохранение изображений. Если экспорт CVAT не
   содержит фотографий, скрипт при запуске попросит указать папку с оригиналами.
3. Запустите:

```powershell
python extract_balanced_cvat_crops.py
```

4. Укажите скачанный ZIP, выберите номера нужных классов и число фрагментов на
   класс.

Скрипт не создаёт искусственные дубликаты. Если у класса меньше фрагментов, чем
запрошено, он сохраняет все доступные и отмечает нехватку в `selection_report.csv`.
Отбор идёт по очереди из разных исходных фото, чтобы не заполнить класс кусками из
одного и того же кадра.

В консоли для каждого класса показываются два числа: `всего аннотаций` и `пригодно`.
Если они различаются, часть разметки не имеет геометрии, повреждена или не может быть
преобразована в фрагмент. Скрипт умеет читать COCO-полигоны, RLE-маски и bbox.

Результат:

```text
dataset_balanced_crops/
  01_ACh/
  02_TFCH/
  selection_report.csv
  metadata.csv
```

При выборе `Закрасить всё вне полигона` скрипт оставляет внутри фрагмента только
материал выделенного класса; пространство за полигоном становится нейтрально-серым.
