# Границы фаций: rule-based demo

Запуск:

```powershell
python facies_boundary_app.py
```

Приложение открывает фотографию, слева показывает исходник, справа — копию с
полупрозрачными пакетами без подписей. Оно ищет вытянутые малонасыщенные столбики керна,
анализирует яркость и плотность тонкой слоистости по вертикали, а границу
ставит только при устойчивом изменении текстуры. Соседние пакеты с одинаковым
предварительным кодом объединяются.

Цвет служит только для того, чтобы увидеть контуры; он не несет названия или
класса фации. Это правило-ориентированный baseline без обучения. Он годится для быстрой
визуальной проверки того, где алгоритм видит устойчивую смену пакета. Для
окончательного определения фаций и устойчивой работы на разных типах съёмки
следует обучить YOLO Segmentation на CVAT-полигонах.
