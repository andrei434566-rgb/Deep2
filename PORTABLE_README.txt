KERN ANALYZER — ПЕРЕНОСИМАЯ WINDOWS-СБОРКА

1. Полностью распакуйте Kern_Analyzer-Windows.zip в обычную папку.
2. Запустите Kern_Analyzer.exe.
3. Не переносите один EXE отдельно: папка _internal обязательна.

Python и установка библиотек не требуются. OCR русского и английского текста
включён в сборку. Веса модели фаций намеренно не встроены: выберите свою .pt
через меню «Модель». Проекты и результаты сохраняются рядом с программой в
папке «Kern Analyzer Data».

Эта GitHub-сборка использует CPU-версию PyTorch, чтобы единый ZIP укладывался
в ограничение GitHub 2 ГБ. Распознавание модели работает на CPU. Дообучение на
NVIDIA выполняйте из исходного проекта в CUDA-окружении согласно MODEL_GUIDE.md.
