# Автоматическая подготовка датасета: Excel + JPG

В Kern Analyzer выберите **File → Импорт Excel + JPG для обучения…**, затем:

1. выберите Excel с послойным седиментологическим описанием;
2. выберите папку с JPG-фото керна;
3. программа сама найдёт столбцы месторождения, номера скважины, интервала отбора керна, интервала и мощности фации, названия/кода/индекса фации, свободного литологического описания и отдельных 16 параметров;
4. для каждого фото программа сначала возьмёт скважину и интервал из имени файла, затем попробует OCR подписи, а при отсутствии обоих источников предварительно заполнит интервалами керна из Excel;
5. проверьте единую таблицу сопоставления фото. Если один интервал керна приходится на несколько неизвестных фото, программа предложит только предварительное равное деление и явно пометит его как требующее проверки;
6. строки Excel сопоставятся с фото по номеру скважины и пересечению глубин;
7. на физические столбики керна будут наложены редактируемые слои точной мощности с фацией, месторождением, скважиной, интервалом керна и литологическими параметрами.

На выходе создаётся новый проект и файл excel_jpg_import_report.txt. В нём перечислены источники интервалов и проблемные фото. В имени фото допустимы и пробелы, и тире: например, `Р-31 3002,00–3004,96 (1).jpg`. Для автоматического чтения подписи нужен установленный Tesseract OCR с русским языком; ручной ввод интервала доступен всегда.

Если описания ещё нет, добавьте фотографии и выберите **File → Автоматически определить интервалы на фото…**. Программа найдёт устойчивые визуальные границы, создаст редактируемые маски и заполнит глубины из имени файла. Такие строки намеренно не получают геологическое имя автоматически: назначьте фацию в карточке интервала, после чего её можно использовать для обучения.

## Как устроена привязка

Интервал каждого JPG сопоставляется с пересекающимися фациями Excel. Интервалы фаций раскладываются по обнаруженным колонкам керна в порядке чтения слева направо и сверху вниз. Высота маски определяется отношением мощности фации к глубинному диапазону колонки: слои разной толщины не превращаются в типовые равные блоки. Если отдельный столбец «Толщина/мощность фации» расходится с разностью «подошва − кровля» более чем на 0,01 м или 2 %, импорт пишет предупреждение и использует кровлю с подошвой.

Excel-наложение ускоряет разметку, но не становится эталоном молча. Все такие контуры имеют статус «требует проверки». Откройте карточку слоя, проверьте границы и точный вариант `код@индекс`, затем отметьте **«Фация и границы проверены»**. Только после этого слой попадёт в обучение.

Перед массовым дообучением проверьте несколько десятков фото из разных скважин: совпадение скважины, верх/низ интервала и геометрию границ.

## Что запоминается при дообучении

Основная метка финальной модели — стабильная пара `код@индекс` из встроенного справочника. Наблюдённые 16 параметров сохраняются отдельно в `attributes.jsonl`, а исходные поля Excel — в `source_metadata`: месторождение, скважина, интервалы керна и фации, мощность и исходное литологическое описание. Это сохраняет связь слоя с первоисточником при переносе датасета на компьютер, где находится модель.

В карточке фации все описательные параметры независимы: в каждом выпадающем списке есть пункт «Самостоятельный выбор…» для своего значения. Колонка «Литология» на планшете и в Word/PDF-отчёте временно не показывается.
