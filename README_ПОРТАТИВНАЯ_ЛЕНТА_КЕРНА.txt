СБОРКА ЕДИНОЙ ЛЕНТЫ КЕРНА
==========================

Это автономная Windows-папка. Python и интернет не нужны.

Как запустить
-------------
1. Дважды щёлкните «Запустить сборку ленты керна.bat».
2. В открывшемся окне выберите папку с фотографиями одной скважины.
3. Дождитесь сообщения «Готово».

Результат появится в выбранной папке с фото:
  _core_tape_review\review.html

Откройте review.html в браузере. В нём будут:
- все исходные фото с зелёными прямоугольниками найденных колонок;
- отдельные прямоугольные бинарные маски;
- вырезки колонок;
- одна или несколько страниц единой вертикальной ленты;
- manifest.json с точными исходными и склеенными координатами.

Порядок
-------
По умолчанию фото сортируются по имени, а колонки на каждом фото идут
слева направо. Перед обработкой проверьте порядок файлов в Проводнике.

Если результат уже существует, программа не перезаписывает его. Удалите
старую папку _core_tape_review после проверки или запустите EXE из командной
строки с параметром --output "ПУТЬ_К_НОВОЙ_ПАПКЕ".

Важно
------
Программа выделяет физические колонки керна прямоугольниками. Она пока не
назначает фации и не использует SAM. Эти результаты предназначены для
следующей стадии: привязки к Excel и формирования обучающей разметки.


Аудит Excel и лент
------------------
1. Рядом положите папки скважин. В каждой папке должны быть Excel с фациями
   и папка результата сборки _core_tape_review с manifest.json.
2. Дважды щёлкните «Запустить аудит фаций.bat» и выберите общую корневую
   папку всех скважин. Для одной скважины можно выбрать её папку.
3. Если рядом найдено несколько Excel, программа попросит выбрать нужный;
   она не угадывает файл и ничего не меняет в исходных данных.

Результат появляется в выбранной корневой папке:
  _facies_audit\facies_audit.html
  _facies_audit\facies_summary.csv
  _facies_audit\audit_issues.csv
  _facies_audit\facies_audit.json

В отчёте «по бурению» — сумма интервалов фаций из Excel, а «покрыто фото» —
часть этих интервалов, которая подтверждена диапазонами в именах JPG. Аудит
показывает пустые названия фаций, несовпадения скважин, ошибки имён файлов и
перекрывающиеся строки Excel. Он не обучает модель и не создаёт best.pt:
сначала результаты и баланс классов нужно проверить.
