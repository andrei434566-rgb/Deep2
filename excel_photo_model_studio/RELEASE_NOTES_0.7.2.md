# Excel Photo Model Studio 0.7.2

## Что нового

- Массовый архив рекурсивно ищет Excel и фото, предлагает однозначные пары скважин и распознаёт их в фоне. Неоднозначные пары остаются на ручную проверку; прогресс сохраняется после каждой скважины.
- Общий датасет строится только из подтверждённых масок. Одна команда последовательно обучает YOLO11-seg для фаций и Qwen3-VL LoRA для кратких описаний на CUDA GPU.
- Исправлено сравнение коротких и полных Windows-путей к Excel, фотографиям и сохранённым проектам.
- Программа сохраняет даже один подтверждённый интервал. Для обучения нужны независимая val-выборка и не менее 20 train / 3 val интервалов с описаниями.

## Установка

Скачайте все ZIP-части версии 0.7.2 и распакуйте в одну папку. Запустите `Excel_Photo_Model_Studio.exe`, не отделяя его от `_internal`. В сборку включены CUDA-сборка PyTorch, библиотеки YOLO и Qwen3-VL, а также OCR. Для обучения необходимы совместимая NVIDIA GPU и драйвер. Базовые веса Qwen3-VL и начальный LoRA-адаптер остаются внешними: укажите локальные пути на вкладке обучения. Для офлайн-обучения YOLO укажите локальный `yolo11s-seg.pt`.

## Проверка

- 204 автоматических теста на локальном Python 3.11 и 3.14; Windows-пути на GitHub Actions проверяются отдельно.
- Перед публикацией GitHub Actions проверяет упакованный CUDA runtime и запускает self-test EXE.
