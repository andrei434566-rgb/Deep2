# Excel Photo Model Studio

Самостоятельная программа подготовки комплекта моделей по архиву Excel и фотографий керна. Она не импортирует Kern Analyzer и хранит собственные проекты, датасеты и кандидаты моделей.

## Целевая схема

Программа ориентируется на стандартизированную таблицу из 22 столбцов:

- №4–5 — интервал отбора керна;
- №13–14 — интервал фации по бурению;
- №19 — название/код фации;
- №20 — ассоциация фаций;
- №21 — обстановка осадконакопления;
- №22 — целевое поле `Краткое описание`.

Отдельная схема из 16 параметров не используется. Текст столбца №22 становится непосредственной целью обучения.

## Что делает программа

1. В интерфейсе принимает один файл `.xlsx`, `.xlsm`, `.xltx`, `.xls`, `.csv` или `.tsv`. Командная строка также поддерживает пакетную обработку.
2. Находит многоуровневые заголовки по смыслу, а не по одной жёсткой позиции. Стандартную нумерацию 1–22 понимает автоматически.
3. Рекурсивно читает фотографии. Скважину и глубину берёт из имени; для неизвестных файлов может применить OCR или ручную таблицу.
4. Связывает фото и строку Excel только при совпадении скважины и пересечении интервала фото с интервалом фации №13–14. Совпадения только по общему интервалу керна №4–5 недостаточно для обучения.
5. Находит физические колонки керна на фото, переводит глубину в координаты изображения и строит маски конкретных интервалов.
6. Сразу после сопоставления показывает выбранное фото с цветными масками найденных интервалов на первом экране. Подробная проверка остаётся на второй вкладке. В датасет попадают только маски, подтверждённые человеком.
7. Собирает два связанных набора данных:
   - YOLO segmentation для границ и класса фации;
   - `caption_dataset.jsonl` и вырезки интервалов для текста столбца №22.
8. Делит данные на `train` и `val` целыми скважинами, а если это невозможно — целыми фотографиями. Одно фото не попадает в обе выборки.
9. Обучает совместимый комплект:
   - `best.pt` — поиск границ и класса фации;
   - `description_best.pt` — формирование черновика столбца №22 по вырезке интервала;
   - `model_contract.json` — контракт подключения в Kern Analyzer.

`best.pt` нельзя одновременно использовать как обычную YOLO-модель и генератор свободного русского текста. Поэтому Kern Analyzer должен загружать оба файла как один комплект. Это сохраняет совместимость YOLO и отделяет проверяемую геометрию от текстовой генерации.

## Установка и запуск

Требуется Python 3.11 или новее.

```powershell
cd excel_photo_model_studio
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Для обучения на NVIDIA установите совместимую CUDA-сборку PyTorch. На CPU обучение разрешено, но будет значительно медленнее. Базовый файл YOLO segmentation `.pt` должен уже находиться на компьютере; приложение не скачивает веса само.

## Рабочий процесс

### 1. Создать проект сопоставления

В приложении выберите один файл Excel/CSV и папку со всеми фотографиями. Служебный проект создаётся автоматически в `%LOCALAPPDATA%\ExcelPhotoModelStudio\projects`; выбирать конечную папку не нужно. Появятся:

- `column_mapping.json` — найденные столбцы каждого файла и листа;
- `photo_map.csv` — скважина и интервал каждой фотографии;
- `matches.csv` — доказанные пересечения фото со строками Excel;
- `annotations.csv` — будущие маски, текст №22 и флаг подтверждения;
- `previews/` — цветные наложения;
- `report.json` — сводка и проблемы.

Интервалы фото можно исправить прямо в таблице приложения. Неподтверждённые фото не создают обучающие маски.

### 2. Проверить маски

На вкладке «Проверка масок» просмотрите каждое цветное наложение. Подтверждайте строку только когда верны одновременно:

- скважина;
- глубины фотографии;
- границы интервала на фото;
- фация №19;
- относящийся к этому интервалу текст №22.

### 3. Собрать датасет

Укажите новую папку. Программа создаст:

```text
dataset/
  data.yaml
  dataset_manifest.json
  caption_dataset.jsonl
  images/train, images/val
  labels/train, labels/val
  crops/train, crops/val
```

### 4. Обучить комплект

Выберите локальную базовую YOLO segmentation-модель, новую папку результата, число эпох и `patience`. Результат:

```text
model_candidate/
  best.pt
  description_best.pt
  model_contract.json
  data.yaml
  dataset_manifest.json
  training_info.json
  description_training_info.json
```

Для текстовой части требуется минимум 5 обучающих вырезок и хотя бы одна независимая контрольная вырезка. Для практического качества нужны сотни и обычно тысячи проверенных интервалов из разных скважин.

## Командная строка

```powershell
python run.py create --excel "D:\archive\excel" --photos "D:\archive\photos" --project "D:\work\project_01"
python run.py refresh --project "D:\work\project_01"
python run.py dataset --project "D:\work\project_01" --output "D:\work\dataset_01"
python run.py train --dataset "D:\work\dataset_01" --base-model "D:\models\base-seg.pt" --output "D:\work\candidate_01" --epochs 50 --description-epochs 40
```

После ручного изменения `column_mapping.json` или `photo_map.csv` выполните `refresh`. Существующие папки проекта, датасета и результата не перезаписываются.

## Выход Kern Analyzer

Модуль `standard_excel.py` фиксирует формат из 22 столбцов и записывает сгенерированное описание строго в столбец №22. Контракт модели указывает Kern Analyzer, какие файлы применять и какие столбцы заполнять.

Текст модели является черновиком. Цвет, зернистость, слоистость и крупные видимые включения модель может учить по фото. Минералогический состав, цемент, состав флюида и другие факты, которых визуально нет на фотографии, нельзя достоверно генерировать только по изображению; их должен подтверждать геолог или дополнительный источник данных.
