# Excel Photo Model Studio

Самостоятельная программа подготовки комплекта моделей по архиву Excel и фотографий керна. Она не импортирует Kern Analyzer и хранит собственные проекты, датасеты и кандидаты моделей.

## Готовая Windows-сборка

Скачать ZIP-релиз 0.3.9 можно со страницы [Excel Photo Model Studio 0.3.9 на GitHub](https://github.com/andrei434566-rgb/Deep2/releases/tag/excel-photo-studio-v0.3.9). Распакуйте архив целиком и запустите `Excel_Photo_Model_Studio.exe`.

## Входной Excel и выходная схема

Во входном Excel нет привязки к номерам колонок. Программа объединяет строки
многоуровневого заголовка и ищет поля по названиям:

- `Интервал отбора керна` — для проверки интервала, прочитанного с фото;
- `Интервал фации по бурению` с подстолбцами `Кровля` и `Подошва` — для масок;
- `Интервал фации по ГИС` — резервный источник, если по бурению фация не пересекается с фото; резерв проверяется по толщине фации;
- название, код или индекс фации — для класса;
- `Краткое описание` — непосредственная цель текстовой модели;
- ассоциация фаций и обстановка осадконакопления — дополнительные признаки.

При чтении подписей фото OCR сопоставляет числа с интервалами отбора керна из Excel и не объединяет числа с линейки из разных строк.

Поэтому `Краткое описание` может быть столбцом №22, №30 или любым другим.
Добавление промежуточных колонок не меняет сопоставление. Номер 22 относится
только к стандартизированному выходному Excel, который создаётся для Kern Analyzer.

## Что делает программа

1. Поддерживает как разбор одной скважины, так и автоматическую очередь из множества пар «Excel + папка фото». В автоматическом режиме папку с архивом можно просканировать: приложение ищет Excel и фото в соседних папках с именами `Фото`, `Photos`, `Images` и в папках, совпадающих с именем Excel. Неоднозначные пары не угадываются.
2. Находит многоуровневые заголовки по смыслу. Для интервалов масок явно предпочитает группу `Интервал фации по бурению`, а не соседнюю группу `по ГИС`.
3. Рекурсивно читает фотографии. Сначала ищет скважину и глубину в имени, затем автоматически распознаёт верхнюю и нижнюю подписи фотографии встроенным Tesseract OCR. OCR-пара автоматически подтверждается только после сверки с интервалом отбора керна в Excel.
4. Связывает фото и строку Excel только при совпадении скважины и пересечении интервала фото с найденным по названию интервалом фации по бурению. Совпадения только по общему интервалу отбора керна недостаточно для обучения.
5. Находит от одной до пяти физических колонок керна на фото, включая короткий или неполный одиночный столбик, исключает линейку глубины, переводит глубину в координаты найденного керна и строит маски конкретных интервалов только внутри него.
   Все глубины рассчитываются в целых сантиметрах: `3.03 м` означает ровно `3 м 3 см`. Если OCR читает на нескольких листах один общий интервал отбора керна, листы автоматически сортируются по номеру и раскладываются подряд по найденным метровым колонкам.
6. Сразу после сопоставления показывает выбранное фото с цветными масками найденных интервалов на первом экране. Подробная проверка остаётся на второй вкладке. В обычном режиме маски подтверждаются пользователем; в автоматической очереди маски принимаются без ручного кликанья только после прохождения всех проверок покрытия фото, керна, интервалов фаций и кратких описаний.
   Каждое выбранное фото обязательно: на нём должны быть найдены физический керн и подтверждённый интервал глубины. Каждый сантиметр керна обязан быть полностью покрыт фацией Excel, непустым полем `Краткое описание` и подтверждённой маской; при любом пропуске сборка обучающего датасета блокируется до исправления.
7. Собирает два связанных набора данных:
   - YOLO segmentation для границ и класса фации;
   - `caption_dataset.jsonl` и вырезки интервалов для поля `Краткое описание`.
8. Делит данные на `train` и `val` целыми скважинами, а если это невозможно — целыми фотографиями. Одно фото не попадает в обе выборки.
9. Создаёт собственную модель без предобученных весов:
   - YOLO-seg строится из YAML-архитектуры со случайной инициализацией и учит границы и классы фаций только по подтверждённым данным проекта;
   - текстовая голова учит поле `Краткое описание` по изображению интервала и классу фации;
   - текстовая голова и контракт 22 столбцов встраиваются внутрь итогового `best.pt`;
   - `description_best.pt` сохраняется рядом как резервный совместимый checkpoint.
10. Применяет созданный `best.pt` к фотографиям нового керна и формирует стандартизированный Excel: фация находится в столбце №19, описание — строго в столбце №22.

Каждая успешно обработанная скважина автоматически регистрируется во внутреннем локальном каталоге. В автоматической очереди приложение последовательно обрабатывает все пары, само подтверждает только полностью проверенные маски, собирает общий датасет и запускает обучение обоих компонентов модели. Если хотя бы один выбранный набор неполон, обучение не начинается: приложение перечисляет причины и сохраняет отчёт рядом с выбранным путём модели. Это не позволяет тихо получить модель из части архива.

## Оптимизация большого архива

- сопоставление, пересчёт, сборка датасета, обучение и анализ запускаются отдельными процессами, поэтому окно приложения не блокируется;
- повторный пересчёт использует кэш разобранного Excel, пока исходный файл и карта столбцов не изменились;
- неизменившиеся предпросмотры масок не создаются повторно;
- предпросмотры больших фотографий уменьшаются до 1800 пикселей по длинной стороне, при этом обучающие маски сохраняют исходные координаты;
- поиск колонок на очень больших фотографиях выполняется на уменьшенной копии и переводится обратно в исходные координаты;
- при сборке датасета каждая фотография читается с диска один раз и обрабатывается последовательно, без хранения всего архива в оперативной памяти.

## Установка и запуск

Требуется Python 3.11 или новее.

```powershell
cd excel_photo_model_studio
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Для обучения на NVIDIA установите совместимую CUDA-сборку PyTorch. На CPU обучение разрешено, но будет значительно медленнее. Готовая базовая модель `.pt` не требуется и не используется.

## Рабочий процесс

### 1. Создать проект сопоставления

В приложении выберите один файл Excel/CSV и папку со всеми фотографиями. Служебный проект создаётся автоматически в `%LOCALAPPDATA%\ExcelPhotoModelStudio\projects`; выбирать конечную папку не нужно. Появятся:

- `column_mapping.json` — найденные столбцы каждого файла и листа;
- `photo_map.csv` — скважина и интервал каждой фотографии;
- `matches.csv` — доказанные пересечения фото со строками Excel;
- `annotations.csv` — будущие маски, краткое описание и флаг подтверждения;
- `previews/` — цветные наложения;
- `report.json` — сводка и проблемы.

Для одной скважины можно использовать эту вкладку напрямую. Для массового запуска откройте вкладку «Датасет и best.pt»: добавьте пары вручную либо нажмите «Автонаходить Excel и фото в папке» для структурированного архива. Очередь сохраняется между запусками. Затем нажмите «Автоматически обработать всё и создать best.pt» — остальные шаги выполняются без подтверждения каждой маски. Счётчик показывает, сколько скважин, фотографий и масок накоплено.

Интервалы фото можно исправить прямо в таблице приложения. Неподтверждённые фото не создают обучающие маски.

### 2. Проверить маски

На вкладке «Проверка масок» просмотрите каждое цветное наложение. Подтверждайте строку только когда верны одновременно:

- скважина;
- глубины фотографии;
- границы интервала на фото;
- фация №19;
- относящийся к этому интервалу текст `Краткое описание`.

### 3. Собрать датасет

Укажите новую папку. Программа создаст:

```text
dataset/
  data.yaml
  dataset_manifest.json
  caption_dataset.jsonl
  images/train, images/val
  labels/train, labels/val
  crops/train, crops/val
```

### 4. Обучить комплект

Выберите размер архитектуры YOLO segmentation, новую папку результата, число эпох и `patience`. Все веса создаются случайно и обучаются только по собранному датасету. Результат:

```text
model_candidate/
  best.pt
  description_best.pt
  model_contract.json
  data.yaml
  dataset_manifest.json
  training_info.json
  description_training_info.json
```

Итоговый `best.pt` остаётся совместимым с Ultralytics и дополнительно содержит checkpoint формирования столбца №22, список фаций и контракт стандартного Excel.

Для текстовой части требуется минимум 5 обучающих вырезок и хотя бы одна независимая контрольная вырезка. Для практического качества нужны сотни и обычно тысячи проверенных интервалов из разных скважин.

## Командная строка

```powershell
python run.py create --excel "D:\archive\excel" --photos "D:\archive\photos" --project "D:\work\project_01"
python run.py refresh --project "D:\work\project_01"
python run.py dataset --project "D:\work\project_01" "D:\work\project_02" --output "D:\work\dataset_01"
python run.py train --dataset "D:\work\dataset_01" --output "D:\work\candidate_01" --architecture yolo11n-seg.yaml --epochs 50 --description-epochs 40
python run.py analyze --model "D:\work\candidate_01\best.pt" --photos "D:\new_core_photos" --output-excel "D:\results\well_description.xlsx"
```

После ручного изменения `column_mapping.json` или `photo_map.csv` выполните `refresh`. Существующие папки проекта, датасета и результата не перезаписываются.

## Выход Kern Analyzer

На вкладке «Новый керн → Excel» программа определяет интервалы и фации, формирует текст столбца №22 и экспортирует таблицу по фиксированной схеме из 22 столбцов. Контракт внутри `best.pt` указывает названия фаций, целевые столбцы и наиболее частые ассоциации/обстановки из обучающих Excel.

Текст модели является черновиком. Цвет, зернистость, слоистость и крупные видимые включения модель может учить по фото. Минералогический состав, цемент, состав флюида и другие факты, которых визуально нет на фотографии, нельзя достоверно генерировать только по изображению; их должен подтверждать геолог или дополнительный источник данных.
