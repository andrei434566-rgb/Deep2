# Excel Photo Model Studio 0.7.3

## Новое

- Массовый архив находит Excel и фотографии, предлагает пары скважин и распознаёт однозначные пары в фоне. Сомнительные пары остаются на ручную проверку; прогресс сохраняется после каждой скважины.
- Из подтверждённых масок собирается общий датасет. Одна команда последовательно обучает YOLO11-seg для фаций и Qwen3-VL LoRA для кратких описаний на CUDA GPU.
- Короткое и полное написание Windows-пути к архиву или проекту больше не считаются разными файлами.
- Перед публикацией EXE проверяются OCR, Excel, контрольный проход YOLO, наличие CUDA-сборки PyTorch и импорт компонентов Qwen3-VL/LoRA.

## Установка

Скачайте все ZIP-части версии 0.7.3 и распакуйте в одну папку. Запустите `Excel_Photo_Model_Studio.exe`, не отделяя его от `_internal`. Python и CUDA Toolkit отдельно не требуются, но для обучения нужны совместимая NVIDIA GPU и драйвер. Базовые веса Qwen3-VL и начальный LoRA-адаптер остаются внешними: укажите их локальные пути на вкладке обучения. Для офлайн-обучения YOLO также укажите локальный `yolo11s-seg.pt`.

Даже один подтверждённый интервал можно сохранить в накопительный датасет. Для обучения нужны независимая val-выборка и не менее 20 train / 3 val подтверждённых интервалов с описаниями.
