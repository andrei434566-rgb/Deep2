# Excel Photo Model Studio 0.4.8

## Исправления

- Исправлена проверка проекции масок: маска может точно следовать видимому силуэту породы и не обязана заливать светлые поля внутри рамки распознанного керна.
- Проверка по-прежнему блокирует слишком узкие маски, выход маски за рамку керна и неполное покрытие интервала по глубине.
- Сохранено повторное использование столбиков, подтверждённых в пошаговой проверке.

## Проверки

- Пройдены тесты распознавания столбиков, глубин, проекции масок и сквозного потока проекта с локальным набором библиотек из предыдущей Windows-сборки.
- Полный тестовый набор и portable smoke test выполняются в Windows workflow релиза.
