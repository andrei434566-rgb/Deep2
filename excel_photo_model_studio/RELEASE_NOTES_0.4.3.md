# Excel Photo Model Studio 0.4.3

## Исправления и изменения

- Источники Excel теперь сопоставляются по названиям заголовков, а не по закреплённым номерам колонок. Перестановка столбцов не должна путать индекс, название фации, краткое описание или интервалы.
- Пара начала и конца интервала фации выбирается из одной группы заголовков `Интервал фации по бурению`; толщина используется только как строгая проверка, а не для выбора похожего крупного интервала керна/ГИС.
- Глубины и толщины сравниваются в целых сантиметрах без допуска: `3.03` и `3,03` эквивалентны, `3.03` — ровно 3 м 3 см, значение без сотых трактуется как `.00`.
- Новый датасет формирует каталог классов из текущих файлов: индекс фации, название фации и краткое описание сохраняются как отдельные смысловые цели; ранее известные классы не подставляются как жёстко заданный список.
- Обновлён единый `best.pt` и его метаданные: контракт целевых полей основан на заголовках, а не на позициях исходной книги. Сохранена совместимость с прежними checkpoint описаний.
- Улучшено выявление физических колонок керна, в том числе узкого/неполного керна; кандидаты-линии линейки и сетки отфильтровываются по геометрии и занятости.
- Усилены проверки согласованности фото, интервалов, масок, кратких описаний и покрытия физических колонок; добавлены регрессионные тесты на обнаружение заголовков, строгое округление, перестановку колонок, метаданные модели и фильтрацию ложных колонок.
- Стандартизированный Excel для нового керна содержит 23 поля, включая отдельные `Индекс фации`, `Название фации` и `Краткое описание`.

## Установка

Распакуйте полный ZIP-архив и запускайте `Excel_Photo_Model_Studio.exe` из распакованной папки. Не перемещайте EXE отдельно от `_internal`.

Сборка для Windows рассчитана на CPU. Для обучения на GPU используйте Python-окружение с совместимой CUDA-сборкой PyTorch.
