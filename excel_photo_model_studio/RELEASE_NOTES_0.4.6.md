# Excel Photo Model Studio 0.4.6

## Исправления

- Заголовок Excel теперь может начинаться в первых пяти строках, а составной многоуровневый заголовок может занимать до пяти строк целиком. Это позволяет корректно связать групповой заголовок интервала с подзаголовками «Кровля» и «Подошва», даже если они стоят в пятой строке.
- Если Excel не дал пригодных строк описания, сообщение показывает причины разбора по листам вместо общей ошибки.

## Проверка

- Добавлены регрессионные проверки заголовков с подзаголовками в четвёртой и пятой строках.
- Тесты разбора Excel: 26 тестов.
