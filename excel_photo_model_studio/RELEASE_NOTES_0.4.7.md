# Excel Photo Model Studio 0.4.7

## Исправления

- Заголовки Excel ищутся в первых четырёх строках; многоуровневая группа заголовка с подзаголовками также поддерживается в пределах четырёх строк.
- Диагностика первого этапа показывает причины пропуска строк Excel по листам и номерам строк.
- Маски фаций теперь следуют видимым боковым границам керна, а не безусловно заливают весь прямоугольник найденной колонки. Редкие светлые/пустые строки контура интерполируются; при недостатке надёжных данных сохраняется проверенная рамка, чтобы не потерять интервал.
- Интервалы фаций проецируются по точным глубинам Excel через границы колонок и фотографий; длины фаций не зашиты в алгоритм.

## Проверки

- Добавлены регрессионные сценарии для границ маски у керна, исключения соседней стрелки и непрерывной раскладки фасций произвольной длины через несколько фотографий.
- Тесты разбора Excel проходят локально. Полные тесты компьютерного зрения и сборка запускаются в Windows workflow релиза.
