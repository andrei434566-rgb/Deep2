# Excel Photo Model Studio 0.4.5

## Исправления

- Заголовки таблицы Excel ищутся в первых трёх строках; глубины, фации и описания привязываются к текущим названиям заголовков, а не к устаревшим номерам столбцов из сохранённой карты.
- Формульные значения читаются из сохранённых результатов Excel. Если результата в файле нет, приложение пересчитывает временную копию книги через установленный Microsoft Excel; исходный файл не изменяется.
- Если формула не может быть пересчитана или строка содержит нераспознанный интервал, точные лист, строка и адреса ячеек выводятся в ошибках парсера вместо молчаливого пропуска.
- Строки с интервалом и фацией, но без краткого описания остаются в результатах разбора и отдельно помечаются предупреждением.
- Строка нумерации колонок исключается только при обнаружении полной последовательности `1, 2, 3, ...`, чтобы не пропускать обычные данные из-за совпадения отдельных чисел.

## Проверка

- Полный набор тестов приложения: 144 теста.
- Добавлены тесты на заголовок в третьей строке, формулы без кэшированного значения, защиту исходной книги и явную диагностику пропущенных значений.

Пересчёт формул требует установленного Microsoft Excel в Windows. Если Excel отсутствует или формула зависит от недоступной книги/надстройки, приложение укажет проблемные ячейки; такие интервалы нельзя использовать для корректных масок, пока значение формулы не станет доступно.
