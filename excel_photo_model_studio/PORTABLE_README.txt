Excel Photo Model Studio 0.6.3
================================

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите Excel_Photo_Model_Studio.exe.
3. Не переносите один EXE отдельно от папки _internal: библиотеки нужны приложению.

В программе выберите один файл Excel и папку со всеми фотографиями. Служебная
папка создаётся автоматически; результаты сопоставления видны во вкладке
сопоставления прямо на фотографии и во вкладке подробной проверки.

В пошаговой сверке можно выбрать другую книгу Excel, даже если первая ещё
читается: приложение затем переключится на выбранный файл. После завершения
мастера подтверждённые рамки керна и порядок столбиков переносятся в проект,
поэтому итоговый пересчёт использует проверенную геометрию, а не запускает
распознавание заново. Если фото изменилось после сверки, координаты не
переиспользуются.

Заголовки таблицы ищутся в первых четырёх строках; составной заголовок вместе
с подзаголовками тоже может занимать до четырёх строк. Если строки Excel не
разобраны, первый этап показывает причины с листом и номером строки.

Входной Excel распознаётся по названиям столбцов. «Интервал фации по бурению»
и «Краткое описание» могут находиться в любой колонке, включая №30. Для фото
без интервала в имени программа автоматически читает подпись встроенным OCR.
Для каждого фото выбирается одна система глубин: по бурению или по ГИС.
Системы не смешиваются для соседних фаций. Явные подписи фото имеют приоритет;
при неизвестной системе сравнивается покрытие, с предпочтением бурению при
равенстве. Проверяется толщина фации. OCR отдельно читает глубины столбиков,
а маски начинаются от найденного физического керна, не от строки с цифрами.
Полный аудит каждой фотографии, распознанных колонок, интервала и масок
сохраняется в photo_inventory.csv внутри служебной папки проекта.

Сначала программа находит физические столбики керна и только затем помещает
внутрь них интервалы фаций. Маски следуют видимым боковым границам керна;
редкие светлые разрывы контура интерполируются. Линейка глубины исключается. Поддерживаются от
одного до пяти столбиков, включая короткий или неполный одиночный столбик.
Глубины считаются в целых сантиметрах: 3.03 м = 3 м 3 см. Фото располагаются
по возрастанию глубины; длинная фация может продолжаться на следующей фотографии
с тем же кратким описанием. Восстановление последовательности по Excel допустимо
только при согласовании измеренной длины и опорных глубин. Нельзя произвольно
сжать длинный столбик до короткого остатка интервала. Если общей подписи
недостаточно для определения положения страницы, программа не угадывает его.

Все выбранные фото обязательны: на каждом должны быть найдены физический керн
и интервал глубины. Каждый сантиметр керна должен быть закрыт фацией, кратким
описанием и подтверждённой маской. Проверяются реальные маски всех столбиков,
а не только совпавшие числа: пропуски, конфликтующие перекрытия, потерянные
строки Excel и неподтверждённые данные блокируют сборку датасета и обучение.

ПОСЛЕ ОБНОВЛЕНИЯ: выполните «Пересчитать после исправлений» для прежнего проекта.
Старый отчёт и прежние подтверждения нельзя использовать как проверку новых
масок. После успешного пересчёта создайте новый датасет и обучите новую модель.
Изменение исходников или сопоставления делает прежнюю проверку устаревшей.

Программа не требует отдельной установки Python. В эту редакцию включена
CUDA-сборка PyTorch 2.10 с runtime CUDA 12.6. Для обучения необходима
совместимая NVIDIA GPU и драйвер; отдельный CUDA Toolkit устанавливать не нужно.
Если CUDA/GPU недоступна, обучение завершится понятной ошибкой без перехода на CPU.

Сначала подтвердите все маски одной скважины. Только после успешной проверки
фото и маски копируются в локальный кэш `%LOCALAPPDATA%\ExcelPhotoModelStudio\confirmed_wells`.
Исходную папку с фото потом можно перенести; кэш переживает перезапуск приложения.
Следующие скважины добавляются отдельно, а новый YOLO-датасет включает весь кэш.

Экспорт создаёт стандартный Ultralytics YOLO segmentation-датасет с `data.yaml`,
`images/train|val`, `labels/train|val`, а также вырезки подтверждённых интервалов,
связанные с краткими описаниями из Excel. Сначала YOLO11-seg дообучается на CUDA
GPU 0, затем отдельный символьный декодер учится на CUDA писать черновик описания
по вырезке интервала, индексу фации и толщине всего интервала. Результат содержит
обычный YOLO `best.pt` и, если есть хотя бы двадцать обучающих интервалов и три
независимых проверочных, `description_best.pt`. Иначе `description_training_info.json`
объясняет, почему обучение текста пропущено, и анализ использует подтверждённое
описание класса. Нейросетевой геологический текст нужно проверять перед применением.

Наличие best.pt не гарантирует качество на новых фотографиях. Проверяйте
сегментацию на отложенных скважинах; безошибочное распознавание любых исходных
снимков не гарантируется.
