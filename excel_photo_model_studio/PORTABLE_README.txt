Excel Photo Model Studio 0.3.4
================================

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите Excel_Photo_Model_Studio.exe.
3. Не переносите один EXE отдельно от папки _internal: библиотеки нужны приложению.

В программе выберите один файл Excel и папку со всеми фотографиями. Служебная
папка создаётся автоматически; результаты сопоставления видны во вкладке
сопоставления прямо на фотографии и во вкладке подробной проверки.

Входной Excel распознаётся по названиям столбцов. «Интервал фации по бурению»
и «Краткое описание» могут находиться в любой колонке, включая №30. Для фото
без интервала в имени программа автоматически читает подпись встроенным OCR.

Сначала программа находит физические столбики керна и только затем помещает
внутрь них интервалы фаций. Линейка глубины исключается. Поддерживаются от
одного до пяти столбиков, включая короткий или неполный одиночный столбик.
Глубины считаются в целых сантиметрах: 3.03 м = 3 м 3 см. Листы одного общего
интервала автоматически располагаются по возрастанию глубины; длинная фация
может продолжаться на следующей фотографии с тем же кратким описанием.

Программа работает без установленного Python. Для обучения моделей на NVIDIA
нужен совместимый драйвер видеокарты. Веса базовой модели выбирать не нужно:
новая YOLO segmentation-модель обучается с нуля только на подтверждённых слоях.

Единый best.pt содержит сегментацию, классы фаций и модель формирования текста
столбца №22. Рядом сохраняются description_best.pt и model_contract.json для
контроля и совместимости. Во вкладке анализа best.pt создаёт стандартизированный
22-столбцовый Excel для новых фотографий керна.

Автоматически сформированные интервалы и описания требуют проверки геолога.
