Excel Photo Model Studio 0.2.0
================================

1. Полностью распакуйте ZIP в отдельную папку.
2. Запустите Excel_Photo_Model_Studio.exe.
3. Не переносите один EXE отдельно от папки _internal: библиотеки нужны приложению.

Программа работает без установленного Python. Для обучения моделей на NVIDIA
нужен совместимый драйвер видеокарты. Веса базовой YOLO segmentation-модели .pt
пользователь выбирает самостоятельно; приложение не скачивает модель из сети.

Комплект создаваемой модели:
- best.pt — сегментация и класс фации;
- description_best.pt — текст столбца №22;
- model_contract.json — контракт подключения к Kern Analyzer.

Автоматически сформированные интервалы и описания требуют проверки геолога.
