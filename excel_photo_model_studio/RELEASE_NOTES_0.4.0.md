# Excel Photo Model Studio 0.4.0

## Сопоставление Excel и фото

- Одна система глубин для всего фото: по бурению или по ГИС, без смешивания соседних фаций. Система сохраняется в карте фотографий.
- Исправлены потеря строк с пустыми глубинами по бурению и заполненным ГИС, выбор объединённого интервала и влияние общего заголовка Excel на распознавание колонок.
- Интервал предыдущей скважины больше не переносится в следующую. Неоднозначное имя скважины не объединяет фации нескольких скважин.
- Глубины столбиков распознаются отдельно; расчёт маски привязан к физическому керну. Учтены короткие столбики и перенос фаций между фото.
- Последовательность не может произвольно сжать метры керна до нескольких сантиметров. Проверенные OCR-глубины защищены от противоречащей им раскладки по Excel.

## Проверка датасета и модели

- Проверяется покрытие фактически построенными масками, пропуски столбиков, конфликтующие перекрытия, фации и краткие описания. Неполная скважина блокирует обучение.
- Устаревшие результаты сопоставления требуют пересчёта. Копии одного фото не допускаются одновременно в обучающую и контрольную выборки.
- Итоговый `best.pt` объединяет сегментацию фаций и текстовый компонент, обученные с нуля. Краткое описание остаётся черновиком для проверки на независимых данных.
- Анализ нового керна не экспортирует молча неполный Excel; определённые глубины ГИС не записываются как глубины по бурению.

## Обновление и ограничения

Полностью распакуйте архив. Для старых проектов выполните «Пересчитать после исправлений», затем создайте новый датасет и обучите новый комплект модели. Исходные Excel и фотографии не изменяются.

Windows portable — CPU-сборка, без обещания CUDA. Для обучения на GPU требуется отдельное окружение с совместимым PyTorch/CUDA.

Если исходные подписи не читаются, система глубин неоднозначна или папка содержит лишь неизвестную часть общего интервала, программа не подставляет вымышленные глубины. Нужны корректные исходные данные или уточнение сопоставления. Проверки целостности и наличие `best.pt` не гарантируют геологическую точность и безошибочный OCR на любых снимках.
