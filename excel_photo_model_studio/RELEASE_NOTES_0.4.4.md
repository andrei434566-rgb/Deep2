# Excel Photo Model Studio 0.4.4

## Исправления

- Подтверждённые в пошаговой сверке границы физических колонок керна и порядок колонок теперь передаются в проект и используются при итоговой проекции масок. Создание проекта больше не должно незаметно запускать повторный поиск керна и терять проверенную геометрию.
- Подтверждённая геометрия сохраняется с контрольными данными исходного файла. Если фото заменено, старые координаты не применяются — программа сообщает об этом и выполняет новое распознавание.
- Итоговый отчёт показывает, для скольких фото рамки керна были перенесены из пошаговой проверки.
- Пошаговая сверка переносит подтверждённые интервалы, геометрию и порядок также для фото, у которых нет найденных пересечений с фациями; такие фото остаются видимыми в отчёте и не пропускаются.
- Кнопка выбора Excel остаётся доступна во время первоначального чтения. Если пользователь выбрал другую книгу, она будет загружена после завершения текущего чтения, а экран и сопоставление обновятся под выбранный файл.
- Проверка толщины альтернативного интервала по ГИС выполняется строго до сотых, без допуска в один сантиметр.

## Проверка

- Полный набор тестов приложения: 140 тестов.
- Добавлен интеграционный тест, который запрещает повторный запуск детектора после подтверждения рамок в мастере и проверяет, что те же координаты используются итоговыми масками проекта.
- Добавлены тесты на смену Excel в мастере, в том числе пока исходная книга ещё загружается.

Распознанные глубины и маски нужно проверять на исходных данных конкретного проекта. Для диагностики используйте оригинальные JPG/PNG и книгу Excel, а не фотографию экрана с запущенной программой.
